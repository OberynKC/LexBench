# 数据与隐私说明

## 数据保存位置

律衡是本地应用，不联网、不上传。业务数据保存在本机：

- macOS：`~/Library/Application Support/律衡/`
- Windows：`C:\Users\<用户名>\AppData\Roaming\律衡`

数据库文件 `lexbench.db`（运行时含 -wal/-shm 附属文件）与附件目录 `attachments/` 共同构成完整数据。

## 保护边界（请仔细阅读）

- 数据库与附件**未做应用层加密**，以操作系统文件权限保护。任何能以您的系统账户登录并读取该目录的人或程序，都可以直接读取全部数据。
- 建议启用系统全盘加密（macOS FileVault / Windows BitLocker），并为电脑设置登录密码。
- 导出的 Excel、附件 ZIP 与备份 ZIP 同样未加密，请存放在受控位置。

## 联网行为

应用不发起网络请求（生产页面内容安全策略禁用连接）。系统通知、文件对话框等能力仅调用本机系统 API。

## 演示数据

演示数据全部为占位虚构信息，仅供试用；请勿据此判断任何真实法律事项。
