# 律衡 0.3.0 Pre-release

律衡是面向中国执业律师的本地个人工作台。本版本用于功能试用和反馈，**请使用虚构资料，不用于真实办案数据**。

## 主要功能

- 以案件关联客户、合同、收费期次、发票与附件。
- 待办与截止日程同步；保全到期预警、提醒中心及系统通知。
- 办案笔记支持 Markdown、草稿自动保存、最近 20 版历史与恢复副本。
- Cmd/Ctrl+K 搜索案件、客户、合同、笔记、待办、日程与保全。
- Excel 十表及附件 ZIP 导出；含附件的完整备份、恢复预检与自动恢复点。
- 明暗主题、中文界面与 macOS 窗口菜单。

## 平台与安装

- macOS：Apple Silicon（arm64），运行时要求 macOS 13 及以上；ad-hoc 签名、未公证，最低系统未逐版本实测。
- Windows：x64，运行时要求 Windows 10/11；未签名测试包，**未完成实机验收**。

请按[安装与升级说明](../installation.md)核对下载来源与 SHA-256。出现开发者身份或信誉提示时，核验后决定是否试用；出现文件损坏、恶意软件提示或哈希不一致时停止安装并反馈。

## 使用边界

- 所有期限均手工录入，须自行核对。应用不计算法定期限、不提供法律意见。
- 完全退出或休眠期间不推送通知。系统授权和勿扰设置可能影响显示。
- 数据库、附件、导出与备份均未做应用层加密，请使用系统账户保护及全盘加密。
- 导出用于阅读和分析；恢复应使用应用生成的备份 ZIP，恢复会整体替换当前数据。
- 恢复上限：压缩 256 MiB、总解压 512 MiB、单文件 256 MiB、清单 4 MiB、20,000 条目。超限备份会被拒绝，备份生成成功不等于已经验证可恢复。
- 不提供自动更新；升级前先备份，再手动安装新版本。不要直接用旧版本打开已迁移的数据库。

macOS 已验证主要业务流程、原生附件操作、导出、完整备份恢复、0.2.0 升级及安装移除重装。Windows 安装包已通过构建和包内检查，尚未实机验收。系统通知、休眠唤醒，以及 macOS 经系统单应用许可后的首次启动和默认数据目录未完成本轮实测；带下载隔离标记的 Mac 包会触发 Gatekeeper 提示，请按安装说明处理。其他系统版本、跨平台恢复及极端磁盘故障场景的覆盖有限。建议先用虚构资料验证所需流程。
