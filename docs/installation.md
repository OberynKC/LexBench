# 安装与升级

## 支持平台

- macOS 13 及以上（Apple Silicon，arm64）
- Windows 10/11 64 位（x64，**当前版本未完成实机验收**）

## 安装

**macOS**：打开 `LexBench-0.3.0-macos-arm64.dmg`，将「律衡」拖入「应用程序」。首次启动如提示无法验证开发者，先核对下载来源和哈希，再到「系统设置 → 隐私与安全性」查看是否提供「仍要打开」。如提示文件已损坏、包含恶意软件，或哈希不一致，请停止安装并反馈，不关闭系统安全检查。

**Windows**：运行 `LexBench-0.3.0-windows-x64.exe`，跟随中文向导安装。如出现 SmartScreen 提示，先核对来源和哈希；确认下载无误且愿意试用后，可选择「更多信息 → 仍要运行」。

本版本为未购买商业签名的测试包：macOS 为 ad-hoc 签名且未公证，Windows 未签名。可能触发系统信誉或开发者身份提示。请仅从本仓库 Releases 下载并用 SHA256SUMS.txt 校验。系统最低版本来自运行时要求，不代表已逐版本实测。macOS 经系统单应用许可后的首次启动及默认数据目录尚未完成本轮实测；若系统未提供许可入口或许可后仍不能启动，请停止操作并反馈。

## 校验

下载 `SHA256SUMS.txt` 后，在下载目录计算安装包的 SHA-256 值：

```bash
# macOS（终端）
shasum -a 256 LexBench-0.3.0-macos-arm64.dmg
# Windows（PowerShell）
Get-FileHash .\LexBench-0.3.0-windows-x64.exe -Algorithm SHA256
```

将输出的哈希值与 `SHA256SUMS.txt` 中同名文件所在行比对（大小写不影响比对结果），一致后再安装。

## 升级

无自动更新。安装新版本前建议先在应用内执行「设置 → 备份数据」，再直接安装覆盖；数据库会自动升级，数据保留。新版本升级过的数据库请勿再用旧版本打开；如需退回旧版本，请在旧版本中恢复升级前生成的备份。

## 卸载

卸载程序默认保留数据目录。如需彻底清空，先备份并完全退出应用，再按[数据与隐私说明](data-and-privacy.md)中的位置处理数据目录。
